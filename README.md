# SkyFitnessPro

SkyFitnessPro — веб-приложение с каталогом фитнес-курсов и онлайн-тренировками для занятий дома. Курсы, тренировки и прогресс пользователя загружаются и сохраняются через API.

## Возможности

- Просмотр каталога курсов, загружаемого из API, без обязательной авторизации.
- Просмотр страницы курса с описанием и направлениями.
- Регистрация и вход с проверкой email и пароля, отображением ошибок API и закрытием окна после успешного входа.
- Добавление и удаление курсов через API.
- Просмотр выбранных курсов и прогресса в профиле; выход из аккаунта и сброс прогресса курса.
- Выбор тренировки из списка, загружаемого для курса; завершённые тренировки отмечаются по данным прогресса.
- Просмотр страницы тренировки со встроенным YouTube-видео и прогрессом по упражнениям. Прогресс можно заполнить и сохранить через API.
- Кнопка прокрутки главной страницы наверх.

## Технологии

- [Nuxt 3](https://nuxt.com/) и [Vue 3](https://vuejs.org/)
- TypeScript
- Tailwind CSS
- Pinia
- Vitest и Happy DOM для unit-тестов

## Установка и запуск

Требуются Node.js и npm.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

### Сборка и предпросмотр

```bash
npm run build
npm run preview
```

### Тесты

```bash
npm run test:run
```

В репозитории есть unit-тесты для валидаторов и обработки ошибок. Они не являются полным интеграционным тестированием всех сценариев приложения.

## API

Приложение использует API WeDev:

- Базовый адрес: `https://wedev-api.sky.pro/api/fitness`
- Каталог курсов: [https://wedev-api.sky.pro/api/fitness/courses](https://wedev-api.sky.pro/api/fitness/courses)

Через API загружаются курсы, тренировки и данные пользователя; авторизованные запросы используются для управления курсами и прогрессом.

Документация API: `webdev-hw-api`.
